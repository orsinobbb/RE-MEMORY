# RE:MEMORY P0 Implementation Plan
> For agentic workers: use superpowers:executing-plans for the core; bounded independent UI/research work may use parallel agents.
**Goal:** runnable six-view local prototype, guarded real MixRoute calls, reproducible evaluation, competition deliverables.
**Architecture:** modular FastAPI engines backed by SQLite; static UI uses documented JSON contracts.
**Tech Stack:** Python 3.12, SQLite FTS5, Pydantic, OpenAI SDK, native JS, pytest, Playwright.
**Spec:** ../../design.md and ../../project-v5.txt.

## Global Constraints
- Synthetic data only; keys only local .env, never frontend/Git/reports.
- API cap US$35, reserve US$15, first experiments target ≤US$5.
- No scan of other projects, arbitrary shell, auto recharge, public deployment or submission.
- Completion requires actual tests; billing/model/calibration UNKNOWN must remain explicit.

## Review Focus
- Ambiguous aliases and unknown questions must not execute wrong tasks.
- Missing evidence, conflicting/expired constraints and nonexistent artifacts block continuation.
- Concurrent deliveries/retries must not duplicate outcomes or overspend.
- Untrusted evidence/HTML cannot execute scripts or override tools.
- Tiny contexts and unknown pricing are observable blockers.
