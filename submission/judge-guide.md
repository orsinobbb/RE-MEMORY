# 評審導覽

先依 README 啟動本機，開啟 http://127.0.0.1:8791/#workspace。

1. 輸入需求並按「找回工作脈絡」。
2. 確認專案、目標與限制，選 MixRoute 自動選模（SMART）並按確認接續；Session 自動建立。
3. 同頁查看成品、展開模型用量及下載 Markdown。已完成任務只讀取保存成果。

可試「請接續鋼琴樂理教材，完成目前尚未完成的驗收清單。」；此情境已有保存的真實實測證據。新安裝首次操作仍需生成；完成後再次操作可驗證不新增呼叫。要試尚未完成的任務，可輸入「請接續AI 工作管理，完成目前尚未完成的驗收清單。」。

目前使用合成專案，交付物為驗收／接續清單。SMART／FIXED 使用真實 API，金鑰只留本機。左側仍可查看記憶、檢索過程、完整性、保存的 Sonnet→DeepSeek 兩階段實測與離線比較。公開交付頁：https://orsinobbb.github.io/RE-MEMORY/ 。

目前功能為記憶找回與任務接續，尚未支援聊天式多輪追問或累積對話歷史。公開頁是靜態實測與下載入口；互動原型在本機執行。
