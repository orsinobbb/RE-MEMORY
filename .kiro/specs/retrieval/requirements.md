# 有界漸進式檢索：requirements

依據：docs/project-v5.txt（V5）與 docs/design.md。此模組文件提供可執行驗收規則，不減少完整規格。

## 需求與驗收

- **RET-01**：由 L0 日期／專案、L1 稱呼、L2 全文與候選探索開始，辨識後執行 L3 目標／狀態、L4 限制／決策、L5 來源檢查。
- **RET-02**：每輪記錄層級、原因、條件、候選、正反證據、新線索、新資訊、本輪與累積 Token。
- **RET-03**：同一資訊版本不重複計入讀取成本；搜尋有輪次、候選與線索上限，不得無限循環。
- **RET-04**：依足夠證據／候選差距、歧義、無新線索與預算停止；沒有可確認目標不得進入任務執行。
- **RET-05**：高吻合度或明確目標仍不可跳過必要限制、來源與成果依賴。
- **RET-06**：regular JSON 與 SSE 取得相同後端結果；非即時呈現須標示 SAVED REPLAY。
- **RET-07**：E／F 的完整關係探索與 A／B 的具體對照 payload 必須依最終實作、測試與結果確認，不從策略名稱推論已完成。
